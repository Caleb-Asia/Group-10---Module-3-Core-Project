# Presentation Style

* Speak naturally.
* Don't read directly from the script.
* Use the script as a reminder of what needs to be covered.
* Keep explanations short while the application is visible.
* Avoid repeating features.
* Don't explain technical details that aren't relevant to the current screen.
* If something breaks, stay calm and move to the backup plan.

---

# Final Goal

The presentation should feel like a single story:

**Problem → Solution → Technology → User Journey → Backend → Testing → Additional Features → Challenges → Close**
